# doitpoorly.net

Plain static site for the doitpoorly build-log persona (3D printing
projects, mostly). No build step: edit the HTML/CSS directly.

Private for now, developing before going live. `CNAME` names the intended
custom domain but nothing is wired up in DNS or GitHub Pages settings yet.

## Structure

- `index.html`, `projects.html`, `about.html` — pages
- `css/style.css` — shared styles
